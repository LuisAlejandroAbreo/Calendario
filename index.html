Plan de 3 Semanas

📘 Semana 1 — Fundamentos y Consolidación

Objetivo: construir una base sólida en Java, fortalecer el vocabulario técnico en inglés y establecer hábitos de comunicación, organización y autogestión. El proyecto comienza desde el modelado y las estructuras fundamentales.

🚀 Semana 2 — Profundización e Integración

Objetivo: aumentar la complejidad técnica. Se incorporan colecciones, interfaces, excepciones, validaciones y estructuras más cercanas a un proyecto real. El inglés pasa de vocabulario a comunicación técnica.

🏆 Semana 3 — Aplicación, Proyecto y Evaluación

Objetivo: integrar todo lo aprendido mediante un proyecto Java funcional, buenas prácticas, debugging, documentación, presentación técnica y simulación de entrevista.

📋 Canvas de Productividad Personal — Estrategia y Metodología

Rol: Desarrollador Junior · Hitos: Java, Inglés & SER · Fecha de cierre: 29 de Septiembre

1. Definición y Propósito del Compromiso

Este sistema está diseñado para estructurar el progreso de aprendizaje como desarrollador junior de Java, el dominio del idioma inglés técnico/conversacional y el fortalecimiento de habilidades blandas (Clase de SER). El objetivo prioritario es garantizar la constancia operativa sin llegar al agotamiento mental, manteniendo el seguimiento de entregables hasta el 29 de septiembre.

2. Organización de Tareas y Sistema de Prioridades

Las actividades se categorizan bajo la matriz de Eisenhower para gestionar el flujo diario:

Alta Prioridad (Bloques Fijos)
  • Clases de Java (14:00 - 17:00): Asistencia activa y aprendizaje de lógica/POO.
  • Clases de SER (18:00 - 19:00): Desarrollo de inteligencia emocional y trabajo en equipo.
Media-Alta Prioridad (Estudio Autónomo)
  • Deep Work Java (08:00 - 10:00): Resolución de algoritmos y práctica en IDE.
  • Inglés Técnico (10:30 - 11:30 / 19:00 - 20:00): Lectura de docs, listening y speaking.
3. Sistema de Recordatorios y Control
  • Alertas de Calendario Visual: Bloques con código de colores (Azul: Java, Verde: Inglés, Naranja: SER, Amarillo: Pausas, Púrpura: Tareas).
  • Bloque Administrativo (11:30 - 12:30): Ventana diaria reservada para resolver trámites, correos y pendientes personales sin interrumpir las horas de estudio.
  • Checklist Diario de Entregables: Control de tareas en NetBeans (uso de Scanner, JOptionPane, bloques try-catch y colecciones ArrayList).
4. Espacios de Concentración y Descanso
Concentración (Deep Work)

Sesiones libres de distracciones (notificaciones desactivadas) durante la mañana y al cierre del día (19:00 - 20:00) para modelar proyectos y hacer commits en el repositorio.

Pausas Activas Obligatorias

• 10:00 - 10:30: Estiramiento y descanso visual.
• 17:00 - 18:00: 1 hora completa de desconexión, ejercicio físico y merienda previa a la Clase de SER.

5. Seguimiento y Métrica de Avance
  • Revisión Semanal (Sábados 09:00 - 11:30): Retrospectiva técnica para verificar que todo el código desarrollado compile correctamente y esté respaldado en el repositorio.
  • Entrega Final (29 de Septiembre): Consolidación del Canvas de Productividad con el 100% de los compromisos de aprendizaje y evidencias de avance registradas.
